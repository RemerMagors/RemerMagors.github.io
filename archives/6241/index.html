8051 单片机原理

单片机概述

单片机就是在一个半导体芯片上集成了中央处理器（Central Processing Unidpjt，CPU）、存储器、输入/输出（Input/Output，I/O）接口、时钟振荡电路、定时/计数器和中断系统等计算机的主要功能部件，单个芯片相当于一台微型计算机，称为微型单片计算机（Single Chip Microcomputer，SCM）简称单片机

单片机适用于各种测量控制和数据处理的场合，也称为微控制器（Micro Controller Unit，MCU）；由于其嵌入式应用的特点又称为嵌入式微控制器（Embedded Micro Controller Unit，EMCU）

一、单片机特点和应用

特点 应用
性价比高 工业自动化领域
集成度高 智能仪器仪表领域
控制能力强 消费类电子产品领域
低功耗 通信领域

二、8051 单片机存储结构

1. 数据存储空间

  • 片内集成有 256B 数据存储空间，可根据需要扩展，外部最多扩展 64KB
  • 内部低 128B 为片内 RAM，高 128B 为 SFR
  • 单片机访问内外部 RAM 指令不同，实际做多可用 RAM 为 64KB+128B

空间分配结构

  • 00H 到 1FH 为 工作寄存器组区（32B）
  • 20H 到 2FH 为 位寻址区（支持字节，位寻址）（16B)
  • 30H 到 7FH 为 用户 RAM 区（设置堆栈、数据存储）（80B）
  • 80H 到 FFH 为 SFR（128B）

2. 程序存储空间

最多支持 64KB，16 位寻址（PC），片内 4KB

ROM 两种使用方式
  • \(\overline{EA}=1\)，内部优先（0000H~0FFFH），外部补充（1000H~FFFFH）
  • \(\overline{EA}=0\)，使用外部（0000H~FFFFH）

三、特殊功能寄存器(SFR，Special Function Register)

累加器 ACC（Accumulator Register）

  • 8 位寄存器
  • 助记符：A
  • 应用广泛
  • 常用符号：ACC

几乎所有的算术运算和绝大多数逻辑运算在累加器 ACC 中完成

寄存器 B

  • 8 位寄存器
  • 主要用于乘除运算，也可做为一般寄存器使用

乘法运算：运算前存放乘数，运算后存放乘积的高 8 位；除法运算：运算前存放除数，运算后存放余数。

程序状态字（PSW，Program State Word）

  • 8 位寄存器
PSW 位 PSW.7 PSW.6 PSW.5 PSW.4 PSW.3 PSW.2 PSW.1 PSW.0
位符号 Cy Ac F0 RS1 RS0 OV - P
位地址 D7 D6 D5 D4 D3 D2 D1 D0
位名称 进位标志位 Carry 半字节进位位（辅助进位位）Auxiliary Carry 用户标志位 工作寄存器选择位 1 工作寄存器选择位 0 溢出标志位 Overflow 系统保留位（用户标志位） 奇偶标志位
位功能 加法最高位进位/减法最高位借位：Cy = 1 加减运算中低四位向高四位进位/借位：Ac = 1 存放一位数据 符号数的运算超出：-128~127 时，OV = 1 存放一位数据 ACC 中有奇数个 1 时 P = 1
OV 的计算
RS1 RS0 用于选择 RAM 工作寄存器区

按顺序从 00H 到 1FH 共计 32B

  • 00 ：0 区 00H~07H
  • 01 ：1 区 08H~0FH
  • 10 ：2 区 10H~17H
  • 11 ：3 区 18H~1FH

堆栈指针 SP(Stack-Pointer)

  • 8 位专用寄存器
  • 指示栈顶在内部 RAM 中的地址
  • 初始值位 07H
“先加后压”规则

入栈时，SP 先加 1 然后将数据入栈（push），出栈（pop）时先读出数据，SP 再减 1

SP 初始值为 07H，则 push 的第一个数据地址为 08H

堆栈指针使用方式
  • 自动方式：再调用子程序或断点时，断点地址自动入栈，程序返回时，断点地址再自动弹回 PC，不需要用户干涉
  • 指令方式：使用专用的堆栈操作指令进行 push/pop 操作，例如保护现场、恢复现场。

数据指针 DPTR

  • 16 位 SFR
  • 当单片机需要访问 ROM，外部 RAM，和 I/O 端口时，提供一个 16 位地址，是 8051 单片机中唯一可以通过指令赋值的 16 位寄存器
  • 可以 16 位操作（DPTR），又可以拆分成两个独立的 8 位寄存器使用：DPH、DPL

I/O 接口

既可采用字节寻址操作，又可采用位寻址操作

汇编语言

这里抄书复习一下

概述

指令是 CPU 控制计算机进行某种操作的命令，指令系统则是全部指令的合集。根据指令形式的不同，指令分为以下两种。

  • 机器指令：又称 机器码，由二进制代码 0 和 1 表示，能够被计算机直接识别和执行。
  • 助记符指令：由助记符表示的 机器指令。由于机器指令不便于被人们识别、记忆理解和使用，因此给每条机器指令赋予助记符号表示，这就形成了助记符指令，它和机器指令一一对应，编写的程序效率高，占用存储空间小，运行速度快，可以编写出最优化的程序。

用助记符书写的指令系统称为汇编语言

用 汇编语言 编写的程序称为 源程序，用 机器语言 编写的程序称为 目标程序。

汇编：把汇编语言编写的源程序翻译成机器语言编写的目标程序的过程

指令格式

[标号:] 操作码助记符 [目的操作数,] [源操作数] [;注释]

例如：

START: MOV A, #01H; (A) <-- 01H

  • 标号：给该条语句起个名字，以便在其他语句中寻找该条语句，代表该条语句所在的地址，
    • 由 1~6 个字符数字串组成
    • 第一个必须是字母
    • 不一定每句都有标号，标号不产生目标代码
      • 调用的标号，在汇编后直接转换成标号处语句的地址
    • 汇编语言中 已经有确切定义的符号不能作为标号，例如：
      • 指令助记符
      • 伪指令
      • 寄存器名
      • …
    • 同一个标号在一个程序中只能定义一次，标号后面必须跟 ;
  • 操作码助记符：规定指令进行何种操作，是指令中不能空缺的部分，一般采用具有相关含义的英语单词或缩写表示
  • 操作数：说明被操作数的源及目的，由源操作数和目的操作数之分。它可以是数据本身或其存储的位置。
  • 注释：便于阅读理解程序，对语句进行的解释说明，不产生目标代码。用 ; 开始表示注释

指令描述符号说明

  • Rn：当前寄存器组的 8 个通用寄存器 R0~R7，n = 0~7
  • Ri：可用作 间接寻址 的寄存器，只能是 R0 和 R1 寄存器，i = 0,1
  • direct：8 位直接地址，在指令中表示直接寻址方式，寻址范围 256B，其值包括 0~127（内部 RAM 低 128B），128~255（内部 RAM 高 128B，即 SFR）
  • #data8/16：8 位/16 位立即数，例如：
    • 8 位：#00H
    • 16 位：#0000H
  • Addr11/16：11 位/16 位的目的地址
  • rel：转移指令中的偏移量，为 8 为带符号补码数，范围 -128~+127
  • DPTR：16 位数据指针
  • bit：位地址
  • A：累加器 ACC 的缩写
  • B：寄存器 B
  • C/Cy：进位标志位，也成为位累加器
  • @：间接寻址寄存器前缀
  • /：加载位操作数前面表示对该位状态取反
  • (X)：X 单元中的内容
  • ((X))：以 X 中的内容为地址的存储单元中的内容
  • ←：数据传送方向
  • $：当前指令起始地址

寻址方式

寻址方式是在指令中寻找操作数或其所在地址的方法，寻址方式越丰富，灵活性越大，能实现的功能也就越强，MSC-51 单片机中共有七种寻址方式，需注意指令的寻址方式的特点 和 寻址范围

寄存器寻址

寄存器寻址是指操作数存放在寄存器中，通过给出寄存器名的形式来访问操作数 的寻址方式

寻址范围：

  • 通用寄存器，4 组 32 个通用寄存器，但**只对当前工作寄存器组的 8 个寄存器寻址，指令中的寄存器名称只能是 R0~R7

  • 部分特殊功能寄存器（SFR），例如累加器A，寄存器B以及数据指针DPTR等

直接寻址

直接寻址是直接给出操作数在存储器中存放地址的寻址方式。可用符号direct表示指令中的直接地址。

寻址范围：

  • 片内RAM低128B，在指令中直接以单元地址形式给出。

  • SFR，除以单元地址形式给出外，还可以以寄存器符号形式给出。

    这里P0是直接寻址

立即寻址

立即寻址是直接在指令中给出操作数的寻址方式，这种操作数称为立即数，立即数有8位和16位两种，可以采用二进制，十进制，十六进制三种形式，立即数前面必须加#。十六进制数以A~F打头的数前要加0以区别于标号

寻址范围：程序存储器，因为立即数是放在程序存储器中的常数

寄存器间接寻址

寄存器间接寻址是通过寄存器给出操作数在存储单元中的存储地址的寻址方式。该寻址方式加，操作数所在的地址存放在指定的寄存器中，而操作数本身则存放在该地址所对应的单元中，间接寻址基顿起前加@

能用与寄存器间接寻址的寄存器有R0,R1,DPTR,SP

注：和C语言中的指针一个意思

寻址范围：

  • 片内RAM单元，只能用寄存器R0,R1，指令为MOV

  • 片外RAM单元，可使用寄存器R0,R1,DPTR，指令为`MOVX``

  • 堆栈操作：指令PUSH,POP是以堆栈指针SP作为间接寻址寄存器的间接寻址方式

    • 因为SP存放栈顶单元的位置

基址加变址寻址

基址加变址寻址是以DPTR和PC的内容作为基址，以累加器A的内容作为偏移量，将两者相加得到的16位地址作为目的地址的寻址方式。可用于读取程序存储器中的数据或者进行程序散转[^1]

本寻址方式指令只有三条

相对寻址

相对寻址主要用于转移指令，一般在转移指令中直接给出要转向的目标地址

汇编完成后，上述指令编译成机器码为

其中：标号LOOP表示目标地址，汇编时，编译器会自动根据SJMP LOOP指令和标号LOOP处的指令的地址自动计算和填入偏移量rel

以下给出具体的程序来说明汇编时rel的计算过程，如

指令地址 机器码 源程序
0004H 80H 4AH SJMP LOOP
… …
0050H 74H 20H LOOP: MOV A, #20H

当CPU执行到SJMP LOOP时，SJMP指令两字节，PC的值为：0004H+02H=0006H，而目标程序LOOP的地址为0050H，汇编时自动计算出偏移量rel

计算方法：rel=目标地址-PC=0050H-0006H=004AH

因此汇编后生成的机器码为80H 4AH，rel是一个带符号的8位二进制补码，取值范围为-128~127，由于rel为8位偏移量，因此目标地址和当前PC的差值必须为-128~127，否则将跳出范围，复数表示往上跳，正数表示往下跳

:exclamation:当强行填入导致计算溢出的数，将保留rel低八位作为跳转

位寻址

位寻址是指令中直接给出位操作数的寻址方式，位寻址只能出现在位操作指令中，位地址可用通用符号bit表示

寻址范围

  • 片内RAM的20H~2FH为位寻址空间

  • 地址能被8整除的特殊功能寄存器[^2]

指令分类介绍

MSC-51 单片机指令系统共有指令111条，可按不同方法进行分类：

  • 按字节数分类：单字节指令（49条）、双字节指令（46条）和三字节指令（16条）
  • 按指令的执行时间分类：单机器周期指令（64条）、双机器周期指令（24条）和四机器周期指令（2条）
  • 按其功能分类：数据传送指令（29条）、算数运算指令（24条）、逻辑运算指令（24条）、控制转移指令（17条）和位操作指令（17条）

数据传送指令

数据传送指令的功能是进行数据传送，数据传送类指令一般不影响状态位。主要分为以下几类指令。

片内RAM传送指令

片内RAM的数据传送是在单片机内部进行的，不需要通过外部总线交换数据，因此速度较快

指令操作码为：MOV

  1. 以累加器A为目的操作数的指令

例题：(R1)=40H, (30H)=12H, (40H)=34H

  1. 以寄存器Rn为目的地址的指令

例题：(A)=40H, (30H)=12H, (40H)=34H

  1. 以直接地址为目的的指令

例题：(R1)=40H, (30H)=12H, (40H)=34H, (A)=78H

  1. 以寄存器间接地址为目的地址的指令

例：(R0)=40H, (30H)=12H, (A)=78H

  1. 以DPTR为目的地址的16位数据传送指令

指令功能是把一个16位立即数送入DPTR寄存器，其中高八位送入DPH，低八位送进DPL

下面两种赋值语句功能一样：

片外RAM传送指令

片外RAM传送指令实际是片外RAM与累加器A之间的传送指令。片外RAM单元只能采用寄存器间接寻址的方式来访问，R0,R1,DPTR可用作间接寻址的寄存器

指令操作码为MOVX

  1. 以DPTR间接寻址的指令

    片外RAM单元的地址存于DPTR中，下列两条指令，第一条指令是读片外RAM单元中的内容复制到A中；第二条指令是把A中的内容吸入片外RAM单元中

    例：将外部RAM1000H单元中的内容送到外部RAM2000H单元，已知(1000H)=12H, (2000H)=34H

  2. 以R0或R1间接寻址的指令

    Ri是8位地址指针，可寻址256B（00H~FFH）的外部RAM，要想寻址64KB范围，可使P2口输出外部RAM的高八位地址（页地址，共256页 00H~FFH），使Ri提供低八位地址（页内寻址，256B/页）

    例：将外部RAM 2050H单元的内容写入累加器A中

ROM 数据传送指令

程序存储器中除了存放程序之外，还会放置一些常数，如表格数据等，这组指令用于再程序存储器中查询表格常数，*并将它送入累加器`A`*，也称它为查表指令，数据传送是单向的。指令操作码为：`MOVC`
  • 单字节指令

:book:

  • 第一条指令将当前指令的PC作为基址寄存器，A作为变址寄存器
    • 寻址范围是当前指令下256B范围之内
  • 第二条指令是以DPTR为基址寄存器，A为变址寄存器
    • 寻址范围是64KB
  • 基址寄存器内容与变址寄存器内容相加形成16位地址
  • 在进行以上两条指令操作时 \(\overline{PSEN}=0\)

例：将ROM 1020H单元内容送入内部RAM70H单元

数据交换指令

数据交换包括全字节交换、半字节交换、高低四位互换三类指令

  1. 全字节交换指令

    指令功能是将A的内容与源操作数相互交换

  2. 半字节交换指令

    指令功能是将累加器A的低四位与Ri间接寻址单元内容的低四位相互交换

  3. 高低四位互换指令

    指令功能是将A中的高低四位互换

例：已知(A)=20H, (R1)=30H, (20H)=12H, (30H)=54H

执行结果：(A)=41H, (R1)=20H, (20H)=52H, (30H)=30H

算术运算指令

指令功能是进行数据的加、减、乘、除算术运算。算术运算指令一般会影响PSW，有如下几类指令

加法指令

  1. 不带进位加法指令

    将源操作数和A中的操作数相加，结果放在A中，并影响各标志位：Cy、Ac、OV和P

    ADD 指令对PSW标志位的影响如下：

    • 若D3向D4进位，则Ac=1，反之为0
    • 若D7进位，则Cy=1，反之为0
    • D6向D7进位情况会影响OV标志，OV=C6⊕C7，其中C6为D6向D7的进位，C7为D7向D8的进位，即Cy
    • A中1的个数影响P
